📖 Sobre o Projeto

O Sistema-PetShop é uma aplicação desenvolvida para auxiliar na organização e no gerenciamento das atividades de um PetShop.

O sistema tem como objetivo facilitar o cadastro de clientes e animais, o agendamento de serviços e a consulta dos horários disponíveis e agendados.

A proposta é oferecer um sistema simples, organizado e fácil de utilizar pelos funcionários do estabelecimento.

🚧 Status do Projeto

Em desenvolvimento.

⚙️ Funcionalidades
Cadastro de clientes;
Cadastro de animais;
Agendamento de serviços;
Consulta da agenda;
Consulta de horários disponíveis;
Registro dos serviços realizados;
Sistema de login e senha para acesso às informações.
💻 Pré-requisitos

Para utilizar o projeto, é necessário possuir:

Computador com acesso à internet;
Git instalado;
Acesso ao repositório do projeto;
Ambiente de desenvolvimento compatível com a tecnologia utilizada na aplicação.
📥 Instalação

Para clonar o repositório, utilize o comando:

git clone URL_DO_SEU_REPOSITORIO

Depois, entre na pasta do projeto:

cd Sistema-Petshop

Para obter mais informações sobre a instalação e configuração, consulte o Guia de Instalação.

🧪 Testes

Após configurar o projeto, devem ser realizados testes para verificar o funcionamento das principais funcionalidades, como:

Cadastro de clientes;
Cadastro de animais;
Agendamento de serviços;
Validação de horários;
Consulta da agenda.

As instruções detalhadas para execução dos testes serão disponibilizadas na documentação do projeto.

🚀 Uso

O sistema deverá ser utilizado pelos funcionários do PetShop para organizar os dados dos clientes, animais e serviços.

O usuário deverá realizar o login para acessar o sistema e poderá utilizar as funcionalidades disponíveis, como cadastro, agendamento e consulta da agenda.

Para mais informações, consulte o Guia de Utilização.
