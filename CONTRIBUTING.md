🤝 Guia de Contribuição

Obrigado pelo interesse em contribuir com o Sistema de Gerenciamento de PetShop.

Como contribuir
Faça um fork do repositório.
Crie uma nova branch para sua alteração.
Realize as modificações necessárias.
Teste as alterações antes de enviá-las.
Faça um commit descrevendo claramente o que foi alterado.
Envie um Pull Request para análise.
Padrão de commits

Procure utilizar mensagens de commit claras e objetivas.

Exemplos:

feat: adiciona cadastro de clientes
feat: adiciona sistema de agendamento
fix: corrige validação de horários
docs: atualiza documentação
Pull Requests

O Pull Request deve explicar:

O que foi alterado;
Qual problema foi resolvido;
Se foram realizados testes;
Se existe alguma alteração que precisa de atenção.

Todas as contribuições devem respeitar as regras descritas no arquivo CODE_OF_CONDUCT.md.
