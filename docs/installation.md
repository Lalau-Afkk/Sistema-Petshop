# 🛠️ Guia de Instalação

## 1. Pré-requisitos

Antes de iniciar, certifique-se de possuir:

* Git instalado;
* Acesso ao repositório do projeto;
* Ambiente de desenvolvimento compatível com a tecnologia utilizada;
* Computador com Windows, Linux ou macOS.

## 2. Clonando o repositório

Abra o terminal e execute:

```bash
git clone URL_DO_REPOSITORIO
```

Depois, acesse a pasta:

```bash
cd sistema-petshop
```

## 3. Configuração

Após clonar o projeto, instale as dependências necessárias de acordo com a tecnologia utilizada na aplicação.

Caso seja necessário configurar um banco de dados, siga as instruções disponibilizadas pela equipe no próprio projeto.

## 4. Executando a aplicação

Execute o comando necessário para iniciar a aplicação de acordo com a tecnologia utilizada.

## 5. Executando os testes

Após configurar o projeto, execute o comando de testes correspondente à tecnologia utilizada.

Os testes devem ser realizados para verificar principalmente:

* Cadastro de clientes;
* Cadastro de animais;
* Agendamento de serviços;
* Validação de horários;
* Consulta da agenda.
