
# 📖 Guia de Utilização

## 🔐 Login

Ao acessar o sistema, o usuário deverá realizar o login utilizando suas credenciais.

O login tem como objetivo proteger as informações cadastradas no sistema.

## 👤 Cadastro de clientes

Na área de clientes, o funcionário poderá cadastrar as informações necessárias do cliente.

O sistema deve verificar se os campos obrigatórios foram preenchidos antes de salvar o cadastro.

## 🐶 Cadastro de animais

Após cadastrar o cliente, será possível registrar os animais relacionados a ele.

## 📅 Agendamento

Na área de agendamento, o funcionário poderá selecionar:

* Cliente;
* Animal;
* Serviço;
* Data;
* Horário.

O sistema deverá verificar se o horário escolhido está disponível antes de confirmar o agendamento.

## 📋 Consulta da agenda

A agenda permite visualizar os atendimentos cadastrados para determinada data.

Caso não existam agendamentos para a data escolhida, o sistema deverá informar que não existem atendimentos cadastrados.

## 💾 Registro dos serviços

Após a realização do atendimento, o serviço poderá ser registrado no sistema para manter o histórico dos atendimentos realizados.
